## Service Template Generator Script

### PHP Script: `generate-service.php`

```php
<?php

/**
 * Service Class Generator
 * 
 * Usage: php generate-service.php ModelName ModelNamespace
 * Example: php generate-service.php Product "App\Model\Product"
 */

if ($argc < 3) {
    echo "Usage: php generate-service.php ModelName ModelNamespace\n";
    echo "Example: php generate-service.php Product \"App\\Model\\Product\"\n";
    exit(1);
}

$modelName = $argv[1];
$modelNamespace = $argv[2];
$serviceName = $modelName . 'Service';

$template = <<<PHP
<?php

namespace App\Services;

use {$modelNamespace}\\{$modelName};
use Illuminate\Support\Facades\DB;
use Illuminate\Database\Eloquent\Collection;

/**
 * {$modelName} Service Class
 * 
 * Handles all business logic for {$modelName} operations.
 * Follows SOLID principles with SRP, DIP, and OCP.
 */
class {$serviceName}
{
    /**
     * Get all records with optional filtering and pagination.
     *
     * @param array \$filters
     * @param int \$perPage
     * @return mixed
     */
    public function getAll(array \$filters = [], int \$perPage = 15)
    {
        \$query = {$modelName}::query();

        // Add your filters here
        
        return \$perPage > 0 ? \$query->paginate(\$perPage) : \$query->get();
    }

    /**
     * Find a record by ID.
     *
     * @param int \$id
     * @return {$modelName}|null
     */
    public function find(int \$id): ?{$modelName}
    {
        return {$modelName}::find(\$id);
    }

    /**
     * Create a new record.
     *
     * @param array \$data
     * @return {$modelName}
     * @throws \\Exception
     */
    public function create(array \$data): {$modelName}
    {
        DB::beginTransaction();

        try {
            \$model = {$modelName}::create(\$data);
            DB::commit();
            return \$model;
        } catch (\\Exception \$e) {
            DB::rollBack();
            throw \$e;
        }
    }

    /**
     * Update an existing record.
     *
     * @param int \$id
     * @param array \$data
     * @return {$modelName}
     * @throws \\Exception
     */
    public function update(int \$id, array \$data): {$modelName}
    {
        \$model = \$this->find(\$id);

        if (!\$model) {
            throw new \\Exception("{$modelName} not found with ID: {\$id}");
        }

        DB::beginTransaction();

        try {
            \$model->update(\$data);
            DB::commit();
            return \$model->fresh();
        } catch (\\Exception \$e) {
            DB::rollBack();
            throw \$e;
        }
    }

    /**
     * Delete a record.
     *
     * @param int \$id
     * @return bool
     * @throws \\Exception
     */
    public function delete(int \$id): bool
    {
        \$model = \$this->find(\$id);

        if (!\$model) {
            throw new \\Exception("{$modelName} not found with ID: {\$id}");
        }

        return \$model->delete();
    }
}
PHP;

$filename = "app/Services/{$serviceName}.php";
file_put_contents($filename, $template);
echo "Created {$filename}\n";
```

### Test Template Generator Script: `generate-service-test.php`

```php
<?php

/**
 * Service Test Generator
 * 
 * Usage: php generate-service-test.php ModelName ModelNamespace
 */

if ($argc < 3) {
    echo "Usage: php generate-service-test.php ModelName ModelNamespace\n";
    exit(1);
}

$modelName = $argv[1];
$modelNamespace = $argv[2];
$serviceName = $modelName . 'Service';

$template = <<<PHP
<?php

namespace Tests\Unit\Services;

use App\Services\\{$serviceName};
use {$modelNamespace}\\{$modelName};
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class {$serviceName}Test extends TestCase
{
    use RefreshDatabase;

    protected {$serviceName} \$service;

    protected function setUp(): void
    {
        parent::setUp();
        \$this->service = new {$serviceName}();
    }

    /** @test */
    public function it_can_create_a_record()
    {
        \$data = ['name' => 'Test'];
        \$model = \$this->service->create(\$data);

        \$this->assertInstanceOf({$modelName}::class, \$model);
        \$this->assertDatabaseHas('{strtolower($modelName)}s', ['name' => 'Test']);
    }

    /** @test */
    public function it_can_find_record_by_id()
    {
        \$model = {$modelName}::factory()->create();
        \$found = \$this->service->find(\$model->id);

        \$this->assertInstanceOf({$modelName}::class, \$found);
        \$this->assertEquals(\$model->id, \$found->id);
    }

    /** @test */
    public function it_can_update_record()
    {
        \$model = {$modelName}::factory()->create();
        \$updated = \$this->service->update(\$model->id, ['name' => 'Updated']);

        \$this->assertEquals('Updated', \$updated->name);
    }

    /** @test */
    public function it_throws_exception_when_updating_non_existent_record()
    {
        \$this->expectException(\\Exception::class);
        \$this->service->update(99999, ['name' => 'Test']);
    }

    /** @test */
    public function it_can_delete_record()
    {
        \$model = {$modelName}::factory()->create();
        \$result = \$this->service->delete(\$model->id);

        \$this->assertTrue(\$result);
    }
}
PHP;

$filename = "tests/Unit/Services/{$serviceName}Test.php";
file_put_contents($filename, $template);
echo "Created {$filename}\n";
```

## Batch Processing Script

### `refactor-models.sh`

```bash
#!/bin/bash

# Batch refactor all models

MODELS=(
    "Product:App\\Model\\Product"
    "Order:App\\Model\\Order"
    "Invoice:App\\Model\\Order"
    "Setting:App\\Model\\Common"
    # Add more models here
)

for model in "${MODELS[@]}"; do
    IFS=':' read -r name namespace <<< "$model"
    echo "Processing $name..."
    php generate-service.php "$name" "$namespace"
    php generate-service-test.php "$name" "$namespace"
done

echo "Refactoring complete!"
```

## Manual Refactoring Checklist

For each model:

- [ ] 1. Create Service class in `app/Services/`
- [ ] 2. Implement CRUD operations (create, read, update, delete)
- [ ] 3. Add transaction handling with try-catch
- [ ] 4. Use early returns for validation
- [ ] 5. Add type hints for parameters and return values
- [ ] 6. Add PHPDoc comments
- [ ] 7. Create test file in `tests/Unit/Services/`
- [ ] 8. Write comprehensive tests (minimum 5 test cases)
- [ ] 9. Update controller to use service (dependency injection)
- [ ] 10. Run tests: `php artisan test`
- [ ] 11. Verify application still works

## Controller Refactoring Pattern

### Before (Controller with business logic):
```php
public function store(Request $request)
{
    $validated = $request->validate([...]);
    
    DB::beginTransaction();
    try {
        $model = Model::create($validated);
        // Business logic here
        DB::commit();
    } catch (\Exception $e) {
        DB::rollBack();
        return back()->with('error', $e->getMessage());
    }
    
    return redirect()->route('...')->with('success', 'Created');
}
```

### After (Controller using service):
```php
protected ModelService $service;

public function __construct(ModelService $service)
{
    $this->service = $service;
}

public function store(Request $request)
{
    $validated = $request->validate([...]);
    
    try {
        $model = $this->service->create($validated);
        return redirect()->route('...')->with('success', 'Created');
    } catch (\Exception $e) {
        return back()->with('error', $e->getMessage());
    }
}
```

## Best Practices Summary

1. **One service per model**: Keep focused and cohesive
2. **Use transactions**: Wrap database operations
3. **Type hints**: Always specify parameter and return types
4. **Early returns**: Validate at method start
5. **Exceptions**: Throw meaningful error messages
6. **Tests**: Minimum 5 test cases per service
7. **Documentation**: PHPDoc for all public methods
8. **DRY**: Extract common logic to private methods
9. **SOLID**: Follow Single Responsibility Principle
10. **Consistent naming**: `ModelService`, `ModelServiceTest`
